> ありがとうございます。今から simple-timer レポジトリを使って、ブラウザ上で動作する、簡単な Web タイマーアプリを作ってもらおうと思います。機能は、指定した時間の経過をカウントダウンで示し、カウントが終了したらアラームオンで知らせる、というものです。画面の中央に、ブラウザサイズに応じてなるべく大きな文字で表示される「hh:mm:ss」形式の設定時間・残り時間の表示をおいて下さい。時間設定は、この表示部分に直接、キーボードで数字を入力するようにお願いします。初期状態での表示は「00:00:00」です。カウントダウンを始める「開始」ボタンを設置して下さい。カウントダウンを始めてからは、同じ位置に「一時停止」ボタンが置かれるようにして下さい。カウントダウンの一時停止中は、「再開」ボタンと「リセット」ボタンを置いて下さい。カウントダウンの終了後には、アラームを停止させる「アラーム停止」ボタンを置いて下さい。このボタンが押されなくても、30秒後にはアラームが停止するようにして下さい。アラームの停止後は画面がリセットされ、初期状態（時間表示が「00:00:00」で設定時間の入力を受け付けており、「開始」ボタンが表示されている状態）に戻るようにして下さい。必要なファイルを直接、レポジトリに作成して欲しいのですが、私の方で操作が必要な部分があれば指示をお願いします。
